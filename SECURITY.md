# Security policy

## Supported versions

Until release branches exist, security fixes land on the default branch only.

This repository also contains local operator artifacts that must not be published:

- `configs/sources.local.json`
- `state/`
- generated date-scoped contents under `inputs/` and `outputs/`

## Reporting a vulnerability

Do not open public issues for suspected security problems in this repository.

Instead, contact the maintainer privately and include:

- affected version or commit
- steps to reproduce
- impact assessment
- any proof-of-concept details needed for validation

Before the first public push, replace this placeholder policy with a real private contact channel.
